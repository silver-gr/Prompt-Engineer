# Claude Research (UI Only)

## Activation
- Available in Claude UI with Research enabled.
- Not available via API.

## Prompting Tips
- Be explicit about scope, time range, and deliverables.
- Provide motivation to guide prioritization.
- Use XML sections for context, requirements, output format.

## Reliability
- Treat citations as starting points; verify critical claims.
- Use a quote-first pass for long documents.

## Limitations
- Rate limits and beta behavior.
- Can hallucinate; cross-check important facts.
