# Task Pattern: Content

## Guidance
- Specify audience, tone, length, and format.
- Provide key points; avoid forcing an outline.
- Request formatting (headings, bullets) only if needed.

## Minimal Template
```
Write a [content type] about [topic].

<context>
Audience: ...
Tone: ...
Key points: ...
Length: ...
</context>

Return in [format].
```
