| Model | Context | Strengths | Use For |

## Core Guidance

- Massive context window (512K) -- excellent for large document analysis
- Real-time data access via X/Twitter integration
- Markdown formatting preferred
- Direct, conversational style works well
- Supports function calling for agentic tasks
- Use clear sectioning for long context inputs

[background -- can be very large given 512K window]

## When to Choose Grok

- Need real-time/current information
- Processing very large documents (>200K tokens)
- Social media / news analysis
- Tasks benefiting from conversational, less formal tone
